## 避免再次漏匯出

新版 collector 在 Ctrl+C／正常離開時，自動保存 `<CSV檔名>.dashboard.json`，先寫摘要再關閉 HTTP 服務。原本手動匯出仍可使用。

程式被強制終止或電腦關機時，仍可從 `.csv.log` 重建。在與 collector 相同的 Python 環境執行：

```powershell
python scripts\recover_dashboard.py data\raw\ARP_OFF_01_20261118_002420.csv.log
```

工具不修改來源檔案、不開啟 COM 埠；若輸出檔已存在會停止，避免覆蓋既有結果。可用 `--out` 指定另一個新檔名。
